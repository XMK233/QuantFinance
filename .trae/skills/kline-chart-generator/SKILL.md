# K-line Chart Generator

This skill generates professional K-line (candlestick) charts for stocks using the same data that was used in the analysis. It creates visualizations that include:

- Candlestick patterns (open, high, low, close prices)
- Technical indicators (MA, MACD, RSI, etc.)
- Volume bars
- Support/resistance levels

## When to Use
- User wants to visualize stock price movements
- Need to see technical indicators graphically
- Want to validate analysis results visually
- Need charts for presentation or reporting

## Input Requirements
- Stock data CSV files (same format as analysis)
- Stock codes/names to visualize
- Time period specification (optional)

## Output
- PNG image files with K-line charts
- Charts saved to appropriate directory
- Professional formatting with legends and indicators
